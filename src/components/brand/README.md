# Brand components

Copied verbatim from `public/logo-kit2/react/`. **Do not hand-edit these four
files** — the kit's README is explicit that nothing in it should be redrawn,
recoloured or regenerated by hand. If the kit is revised, re-copy the folder.

Filenames keep the kit's PascalCase (rather than the repo's usual kebab-case)
precisely so re-copying stays a straight `cp`. They import each other by exact
name (`./SyncMark`, `./SyncIcon`), so all four must stay in this directory.

| File | Exports |
| --- | --- |
| `tokens.ts` | `color`, `radius`, `motion`, `mark` — import these instead of writing hex |
| `SyncMark.tsx` | `SyncMark` (default), `SyncLockup` |
| `SyncIcon.tsx` | `SyncIcon` (default), `SYNC_ICON_NAMES`, `SYNC_ICON_LABELS`, `SyncIconName` |
| `SyncLoaders.tsx` | `SyncSpinner`, `SyncBootLoader`, `SyncSectionLoader` |

## Rules the kit asks reviewers to enforce

- Three loaders, no fourth. Rotation and the running trace mean *waiting* — never
  borrow either motion for decoration or transitions.
- Never two loaders on screen at once.
- Listing grids get Ink skeleton blocks and one shimmer, not a spinner per card.
- Section icons belong on mobile tabs, section headers, listing card badges and
  the dashboard side nav. **Not** the desktop top nav, which stays text only.
- Below 16px, drop the icon and keep the text label.
- Never recolour anything outside Cream, Ink and Electric Lime.

## `sync-logo.tsx` - the app-side lockup (not part of the kit)

Kebab-case on purpose: it is ours, not a copy, so re-copying the kit never
touches it. Use `<SyncLogo>` everywhere a logo appears (header, footer, mobile
menu, auth panel, dashboard rail) rather than the kit's `SyncLockup`.

`SyncLockup` hard-codes `font-family: "Bricolage Grotesque"` inline, but this app
loads Bricolage through `next/font`, which only exposes it under a hashed family
name behind `--font-display`. The literal name matches nothing, so the kit lockup
renders its wordmark in system-ui. `SyncLogo` wraps the kit's `SyncMark`
untouched and sets the wordmark with the repo's `font-display` class instead.
