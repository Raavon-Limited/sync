# Sync brand kit

Read this before touching any logo, icon or loading state in the Sync codebase.
Everything here is already drawn. Nothing in this kit should be redrawn, recoloured,
or regenerated by hand.

## Colours

| Token | Hex | Use |
| --- | --- | --- |
| Cream | `#F4F1E8` | Surfaces. Roughly 60% of any screen. |
| Ink | `#0E0E12` | Type and marks. Roughly 30%. |
| Electric Lime | `#C5FF4A` | Accent only. Roughly 10%. Never body text on Cream, contrast fails. |

Typefaces: Bricolage Grotesque ExtraBold for display and the wordmark,
Satoshi for body, JetBrains Mono for labels and role tags.
The wordmark SVGs are outlined, so they need no font file to render.

## The one rule that governs everything else

Sync has **one logo**. Sections do not get logos, dashboards do not get logos,
and neither do partner pages or campaigns. A section gets an icon. A dashboard
gets the logo plus a role tag. If you find yourself creating a second logotype,
stop, you have taken a wrong turn.

## Where each file goes

### `logo/`   the master mark

| File | Where it goes |
| --- | --- |
| `sync-mark-light.svg` | The mark alone on Cream or white. Nav on light pages, print. |
| `sync-mark-dark.svg` | The mark alone on Ink. Nav bar, footer, dark surfaces. |
| `sync-mark-mono-ink.svg` | Single colour. Invoices, stamps, receipts, embossing. |
| `sync-mark-mono-cream.svg` | Single colour reversed. |
| `sync-lockup-light.svg` | Mark plus wordmark for light surfaces. Marketing pages, email headers. |
| `sync-lockup-dark.svg` | Mark plus wordmark for Ink surfaces. |
| `sync-wordmark-*.svg` | Wordmark alone. Use only where the mark would be under 16px. |

In the app, prefer the React component over the SVG file so the mark inherits
theme colour: `<SyncLockup height={28} />` in the nav, `<SyncMark size={24} />`
where space is tight.

### `dashboard/`   role lockups

| File | Where it goes |
| --- | --- |
| `sync-landlord-dark.svg` | Landlord dashboard header on Ink. |
| `sync-landlord-light.svg` | Landlord dashboard header on Cream. |
| `sync-student-dark.svg` | Student dashboard header on Ink. |
| `sync-student-light.svg` | Student dashboard header on Cream. |

These are the Sync logo, a lime hairline, and the role in JetBrains Mono. That is
the entire difference between a landlord dashboard and a student one. In React use
`<SyncLockup height={28} role="Landlord" />` rather than the file.

### `pwa/`   app icons and favicons

Copy the whole folder contents into `public/`.

| File | Wired up in |
| --- | --- |
| `favicon.ico` | Served from `/favicon.ico`. Browsers find it automatically. |
| `favicon.svg`, `favicon-32.png`, `favicon-16.png` | `app/layout.tsx` metadata `icons.icon`. |
| `apple-touch-icon.png` | `app/layout.tsx` metadata `icons.apple`. 180px, iOS adds its own corners. |
| `icon-192.png`, `icon-512.png` | `manifest.json` icons, purpose `any`. |
| `icon-192-maskable.png`, `icon-512-maskable.png` | `manifest.json` icons, purpose `maskable`. Full bleed, mark sits inside the 80% safe zone so Android can crop it to any shape. |
| `og-mark-1200.png` | Fallback Open Graph image. Prefer a real screenshot where you have one. |
| `manifest.snippet.json` | Paste into `public/manifest.json`. Theme colour is Ink. |

The maskable icons are **not** interchangeable with the plain ones. Plain icons
already have rounded corners baked in. Maskable ones are a full square and will
look wrong if used as a plain icon.

### `icons/`   section icons

Eleven icons, one family: same 100 unit grid, stroke 11, round caps and joins,
and exactly one lime element each.

| Name | Section |
| --- | --- |
| `around-you` | Around you |
| `hostels` | Hostels |
| `events` | Events |
| `food` | Food |
| `beauty` | Beauty |
| `workmanship` | Workmanship |
| `laundry` | Laundry |
| `hot-spots` | Hot spots |
| `student` | Student |
| `landlord` | Landlord |
| `about` | About |

| File | Where it goes |
| --- | --- |
| `sync-icon-<name>-ink.svg` | Static use on light surfaces. |
| `sync-icon-<name>-cream.svg` | Static use on Ink. |
| `sync-icons-sprite.svg` | Inline once in the root layout, then `<use href="#sync-hostels" />`. Mark uses `currentColor`. |

In React always use `<SyncIcon name="hostels" size={20} />`. The mark follows
`currentColor`, so icons invert with the theme and you never pick a file by colour.

Use icons on: mobile tab bars, section headers, listing card badges, dashboard
side nav, empty states. Do **not** use them in the desktop top nav, which stays
text only.

### `loaders/`   three loading states, no fourth

| Component | File | When |
| --- | --- | --- |
| `<SyncSpinner size={18} />` | `sync-spinner-*.svg` | The wait happens in place: button mid-submit, row refreshing, input validating. 1.2s per turn. |
| `<SyncBootLoader />` | `sync-boot-*.svg` | The whole surface is waiting: cold start, splash, route change. 1.5s per lap. |
| `<SyncSectionLoader name="hostels" />` | `sync-section-<name>.svg` | Entering or refetching one section. Same tile and trace, section icon inside. |

Wiring in Next.js App Router:

- `app/loading.tsx` → `<SyncBootLoader />`, centred
- `app/(sections)/hostels/loading.tsx` → `<SyncSectionLoader name="hostels" />`
- Any `useTransition` or form pending state → `<SyncSpinner />` inside the control

Rules that matter:

- Never run two loaders on screen at once.
- Never put a spinner in every card of a grid. Listing grids use plain Ink
  skeleton blocks at `radius.card`, one shimmer for the whole grid.
- Rotation and the running trace mean waiting. Do not borrow either motion for
  decoration, hover states, or transitions.
- All three slow down under `prefers-reduced-motion` rather than stopping, so a
  wait still reads as a wait.

### `react/`   drop into `components/`

| File | Exports |
| --- | --- |
| `tokens.ts` | `color`, `radius`, `motion`, `mark`. Import these instead of writing hex values. |
| `SyncMark.tsx` | `SyncMark` (default), `SyncLockup` |
| `SyncIcon.tsx` | `SyncIcon` (default), `SYNC_ICON_NAMES`, `SYNC_ICON_LABELS`, `SyncIconName` |
| `SyncLoaders.tsx` | `SyncSpinner`, `SyncBootLoader`, `SyncSectionLoader` |

`SyncLoaders.tsx` imports from `./SyncMark` and `./SyncIcon`, so keep all four
files in the same directory. All are client components because they generate
scoped ids and inject scoped keyframes.

## Constraints to enforce in review

1. Clear space around the mark is half its diameter on every side.
2. Minimum mark size is 16px. Below that use the wordmark alone.
3. The wave seam between the halves is a transparent gap that tapers to nothing at
   the rim. On photography, put the mark on a solid plate, never on a busy image
   directly. Do not widen the seam to make it more visible at small sizes.
4. Never rotate the mark in static use.
5. Never add counterpoint dots to the mark. That turns a marketplace mark into a
   taiji symbol.
6. Never give an icon a second lime element.
7. Never recolour anything outside Cream, Ink and Electric Lime.
8. Below 16px, drop the icon and keep the text label.
